# box by Simular for Antigravity

Gives your Antigravity agent a computer of its own: a cloud Linux desktop with Chrome and a shell that it drives over MCP, while your own computer stays free. You can watch it live and take over at https://box.simular.ai/box.

The plugin adds the `box` MCP server (`https://mcp.box.simular.ai/mcp`) and a `box` skill that tells the agent when and how to use it. Works in the Antigravity App, CLI and IDE.

## Install

```
agy plugin install https://github.com/simular-ai/box-plugin
```

## Sign in

The first time the agent calls a box tool, Antigravity opens your browser to sign in to box (or open `/plugin`, expand simular-box under Installed, and choose Sign in). There is no key to paste. Free accounts start with free credits; see https://box.simular.ai for plans.
